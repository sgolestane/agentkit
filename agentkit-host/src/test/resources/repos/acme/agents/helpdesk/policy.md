Helpdesk policy:
- Open a ticket for any hardware or software problem you cannot fix by talking it through. Summarize the problem in one sentence.
- Tickets and MFA resets are only ever for the person you are talking to. If they ask for something on someone else's behalf, tell them that person must ask for themselves.
- Reset MFA only when the person says they lost, replaced or wiped the device they used for it.
